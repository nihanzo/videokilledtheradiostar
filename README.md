# nihanzo — Video Editing Portfolio

A dark, cinematic portfolio site for a video editor & colorist. Static HTML/CSS/JS,
no build step, deployable free on GitHub Pages.

## Run locally
```bash
python3 -m http.server 8756
# open http://localhost:8756
```

## Structure
- `index.html` — page content
- `css/styles.css` — design tokens + styling
- `js/main.js` — nav, scroll reveals, stat counters, portfolio filters, video modal
